It needs the local server, because the page imports the model files directly — the 3D model is the drawing model:

npm install
node tools/render/serve.mjs        # serves on http://127.0.0.1:8099
# then open  http://127.0.0.1:8099/web/walk.html

ORBIT — drag to turn, scroll to zoom, right-drag to pan. WALK — click to capture the mouse, WASD to move, SHIFT to run, SPACE/C for up and down, ESC to release. The walk mode settles you onto whichever storey you are standing over, so you stay on a floor instead of flying through it.

TWO THINGS THIS PACKAGE CANNOT CLAIM

1 · No code was verified. Produced with no outbound web access — every primary source (ncosfm.gov, codes.iccsafe.org, wataugacounty.org, ASCE Hazard Tool, NOAA) returned HTTP 403. No code text was read. Design loads — ground snow, wind exposure, seismic, frost depth, rainfall — are not established. Nothing here may be relied on for permitting.

2 · There is no site information. Four facts are known; everything else is assumed and traceable in docs/01-site-facts-register.md. Commission the wastewater soil evaluation first — on steep NC mountain land it is the commonest reason a house cannot be built where the owner wants it.

NEXT

Liveability, not entourage. Trees were the wrong thing to spend on while rooms were unconvincing. The work that matters next is the stuff that makes a house feel inhabited and legible: a covered entry you can find from the motor court, a real mudroom sequence you can trace from car to kitchen, daylight and switching studied per room, storage that exists, and a site plan that finally describes the ground — driveway grade, cut and fill balance, the septic field, the water source, where stormwater goes.
Every drawing, render and check is generated from one model — model/geometry.mjs, model/openings.mjs, model/fixtures.mjs. Rebuild: node tools/build.mjs && node tools/render/raster.mjs && node tools/check/clash.mjs

Produced by an AI system without site access, without verified code text, and without engineering analysis. A design proposition and coordination study — not a construction document, not an engineered design, and not evidence of code compliance.
