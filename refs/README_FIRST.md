# HOUSE GAUNTLET SYSTEM

A reusable system for running multiple architecture projects without mixing their facts, images, references, or design logic.

Use in this order:

1. Fill out `01_HOUSE_DOSSIER_TEMPLATE.md` for one house.
2. Build an `02_IMAGE_REGISTER_TEMPLATE.md` for that house.
3. Feed the dossier + image register into `03_MASTER_PROMPT_FACTORY.md`.
4. Save the result as that house's own Gauntlet prompt using `04_HOUSE_GAUNTLET_TEMPLATE.md` as the structure.
5. Use `05_PORTFOLIO_ORCHESTRATOR.md` only when running several houses in parallel.

Rule: one house = one dossier = one image set = one gauntlet = one critic loop.
