# PORTFOLIO ORCHESTRATOR

I want to run a portfolio of multiple house projects.

Each house must remain independent.

For each house:
1. read only that house's dossier
2. read only that house's images and reference set
3. generate a house-specific gauntlet prompt
4. create a separate builder/critic structure
5. create a separate progress wall
6. keep known / assumed / open separate
7. never mix images, site assumptions, or references across houses unless explicitly instructed
8. preserve house-specific naming and provenance in every output
9. keep all critic verdicts and artifacts inside that house's own folder
10. compare houses only at the portfolio level after each house has completed its own gauntlet

Output:
- one short summary table of all houses
- one separate gauntlet prompt per house
- one separate list of required files/images per house
- one separate unresolved-information list per house

Do not collapse the houses into one shared prompt.
Do not create one generic house system and apply it indiscriminately.
Preserve the distinct logic of each house.
